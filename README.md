# comedu_portal

영역으로 찾는 정보 수업 도구함 (티쳐무) — 고등학교 정보 수업 자료(웹교과서·수업교안 노트·영역별 학습 자료·제출형 활동지·교사·학급 도구)를
2022 개정 「정보」 교육과정 영역(컴퓨팅 시스템 → 데이터 → 알고리즘과 프로그래밍 → 인공지능 → 디지털 문화)으로 나눠 한 페이지에 모은 단일 HTML 웹앱.

- 진입점: `index.html`
- 배포: 정적 사이트 (Netlify / GitHub Pages)

## 선생님께 — 제출형 활동지를 내 드라이브로 복사해 쓰기
「제출형 활동지 (Apps Script)」 칸의 카드를 누르면 **[교사용 사본 만들기]** 와 **[테스트 페이지]** 를 고를 수 있습니다.

- **교사용 사본 만들기** — 구글의 사본 화면은 새 탭으로 열리고, 지금 탭은 배포까지 따라 하는 그림 안내로 넘어갑니다.
  1. 새 탭에서 **[사본 만들기]** 를 누릅니다.
  2. 사본 시트의 앱 메뉴에서 **시트 준비하기** 를 누르고 권한을 승인합니다.
  3. **확장 프로그램 → Apps Script → 배포 → 새 배포 → 웹 앱** — 실행은 「나」, 액세스는 「모든 사용자」로 두고, 나온 주소를 학생에게 줍니다.
- **테스트 페이지** — 학생 화면을 미리 둘러보는 체험용입니다. 입력한 내용은 티쳐무 선생님의 시험용 시트에 남으니
  실제 학생 정보는 넣지 마세요. 우리 반 학생에게는 3단계에서 받은 선생님 주소를 줍니다.

**프로그래밍 수업 사전 설문지**는 시트 메뉴가 없는 설문지라 안내 차례가 조금 다릅니다 —
① 사본 만들기 → ② (다른 과목이면) Apps Script 편집기에서 과목 이름과 문항 바꾸기 →
③ 배포(**유형 선택은 반드시 「웹 앱」**, 권한 승인은 이때) → 나중에 또 고치면 「배포 관리 → 수정 → 새 버전」.

포털 주소 끝에 `#copy-<앱>` 을 붙이면 그 앱의 안내 화면이 바로 열립니다 (예: `#copy-sw-idea`, `#copy-pre-survey`).

## 파일
| 파일 | 하는 일 |
|---|---|
| `index.html` | 포털 전부. `DATA` 배열이 카드 목록이고, 제출형 활동지의 `teacher` 값이 사본·테스트 링크와 안내를 만든다 |
| `guide-figures.js` | 배포 안내 그림(SVG) — 실제 화면을 단순하게 다시 그린 안내도 |
| `tools/export-guide-images.mjs` | 안내 그림을 PNG 로 뽑는다: `node tools/export-guide-images.mjs` |
| `guide/` | 뽑아 둔 PNG. `<앱>-guide.png` 는 메신저로 보내기 좋은 한 장짜리 전체 안내 |
